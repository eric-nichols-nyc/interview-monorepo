# Writing Samples

This directory contains writing samples used to train AI for personalized cover letter generation.

## Structure

- `cover-letters/` - Previous cover letters you've written
- `emails/` - Professional emails that showcase your communication style
- `documents/` - Other professional writing samples (proposals, reports, etc.)
- `style-guide.md` - Your personal writing style guide
- `prompts/` - AI prompts and templates for cover letter generation

## Usage

1. Add 5-10 samples of your best writing across different contexts
2. Update `style-guide.md` with key elements of your writing style
3. Use samples to train AI models or reference when writing new cover letters

## File Naming Convention

- Use descriptive names: `cover-letter-tech-startup-2023.md`
- Include context: `email-client-proposal-formal.md`
- Date when relevant: `report-quarterly-2024-q1.md`
